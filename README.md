Aplikasi Android khusus untuk **Interactive Flat Panel (IFP / Smartboard)** dan **Smartphone** di lingkungan **SMK NEGERI 1 PANCUR BATU**. Aplikasi ini mengotomatiskan pemutaran lagu kebangsaan **Indonesia Raya** tepat pada pukul **10:00 WIB** setiap hari pembelajaran (Senin – Jumat) dengan konektivitas nirkabel ke speaker sekolah.
